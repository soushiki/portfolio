NYC 311 API tests

Problem
Apps built on a public API break without warning when the API changes how it answers.
Solution
A written test plan and 44 automated tests for New York City's 311 open data API: the response contract, filters and paging, and how it rejects bad requests.
What it changes
GitHub runs them on every change and every morning, so a change in the API shows up as a failing test the same day.
  • Python
  • pytest
  • JSON Schema
  • GitHub Actions
