Minoscreto: use AI without handing over names

Lawyers, doctors and accountants want AI help with documents full of personal data. Minoscreto swaps every name and sensitive entity for a placeholder before the text goes to the AI, then puts the real names back into the AI's answer. It all runs in the browser, so nothing is uploaded anywhere.

How it works

  1. Load a document

    A Word file, or a long PDF or Word case file in "expediente" mode. The file is parsed locally (JSZip for .docx, pdf.js for PDFs).

  2. Detect entities

    Names and other sensitive entities are detected and shown for review before anything is replaced.

  3. Protect and download

    One click downloads the protected document plus its dictionary (placeholder → real value), together, so the dictionary can't be forgotten.

  4. Restore the answer

    Paste the AI's response back in, and the dictionary restores the real names, so the final text is ready to use.

Engineering

Architecture

  • Model: pure logic with no React, covering detection, entities, the dictionary and .docx handling
  • View-models: hooks (useAnonymizer, useRestorer) plus a reducer for state
  • Views: presentational components that only receive the view-model as props

Quality

  • Vitest + Testing Library tests for both the model and the UI
  • An end-to-end benchmark on a generated 600-page case file, with a ground-truth answer key
  • Built with Vite into one self-contained HTML file, which can be sent and opened offline
