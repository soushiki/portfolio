Formato Médico: the paper form, without the paper

A physician fills out the same printed forms all day: lab orders, prescriptions, medical certificates, sick-leave notes and imaging requests. This app reproduces those forms exactly as PDFs, ready to print or send by WhatsApp. It includes a diagnosis search that works offline, on the web and as an Android app.

6form types: lab, prescription, certificate, sick leave, imaging, other
~10,700ICD-10 codes searchable offline, in Spanish
Web + APKone React codebase, packaged for Android with Capacitor
CIevery push builds the Android APK on GitHub Actions

How it works

  1. Pick the form

    Lab orders, prescription, certificate, sick leave, imaging or free-form. Each has its own fields and checkboxes, matching the original paper.

  2. Search diagnoses

    Type part of a name or code to search the bundled ICD-10 (CIE-10) catalog. Up to four diagnoses, or free text.

  3. Generate the PDF

    jsPDF draws onto coordinates measured from the original form, so the output lines up with the paper the patient expects.

  4. Share it

    On Android, "Save / send PDF" opens the native share sheet (WhatsApp, Drive, Files), and "View PDF" opens the phone's viewer.

Decisions worth explaining

Why the ICD-10 catalog is bundled

The popular public ICD-10 lookup site has no API: its search needs a CSRF token and blocks cross-origin requests, so a browser can't query it. Bundling a generated catalog (rebuilt with one script) makes the search instant, independent of a third-party site, and usable without internet.

Why Capacitor instead of a native rewrite

Forms get filled out in the consulting room, often from a phone. Capacitor wraps the same React app as an Android APK with native file access and sharing, so there's one codebase to maintain. A GitHub Actions workflow produces an installable APK on every push, with no local Android setup needed.

Built for a physician in my family and used privately in his practice. Neither the app nor its source code is public, because they contain his real form layout, logo and signature. This page describes the design without exposing any of them. A walkthrough is available on request.
